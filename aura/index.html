Aura

Audio meetings anyone can host. No video, no clutter — just talk, in high-quality sound, built to work with a screen reader.

Join or create a room

This copy of Aura is not connected to a meeting server yet. It needs a LiveKit server address and token endpoint in its settings before anyone can join. If you are the person setting this up, see the README that comes with the project.

Your Aura account

Anyone can join a room as a guest. To create and host a room, you need a free account — that is how Aura knows the room is yours and gives you the host controls. Your account keeps you signed in on this device: using Aura renews your sign-in, so you only type your password again after 90 days away.

Create an account

Use the name of an existing room to join it, or type a new name to create a room. Whoever creates a room is its host. The host can mute or remove people in that room.

Audio quality

You are on the non-secure copy of this page (its address starts with http, not https). Browsers will not switch on your microphone here. Please use the secure address instead: https://joedgreen.github.io/aura/

Schedule a meeting

Plan ahead: Aura emails each guest an invitation with the join link and a calendar file they can add to their calendar in one tap. Guests never need an account.

Tip: use the meeting title as the room name, so the invitation link is easy to recognize.
